# PDF 版式与生成规范

## 1. 版式基线

- 页面：A4 竖版，12-15 页，目标 14 页。
- 风格：知识卡片，温暖纸张色背景、深色正文、单一强调色；视觉语言统一但允许后续版本化。
- 边距：四周至少 18 mm；页脚安全区至少 13 mm。
- 字体：优先 Noto Sans CJK SC、思源黑体或微软雅黑；生成前验证中文字体可嵌入或可正确渲染。
- 正文：单栏为主，正文不得小于 9.5 pt，行距不低于字号的 1.35 倍。
- 元素：固定页眉、页码、模块标签、卡片圆角和留白体系；不得靠缩小字号硬塞内容。
- 字符：自动生成文本中使用普通 ASCII 连字符 `-`，避免特殊连字符导致缺字。

当前视觉样稿可参考 `tools/generate_psychology_of_money_sample.py` 及 `output/pdf/每日精读样稿-金钱心理学.pdf`。它是风格基线，不是必须复用的最终实现。

## 2. 14 页标准骨架

| 页码 | 内容 |
|---:|---|
| 1 | 封面：中文名、原文名、作者、价值主张、阅读时间 |
| 2 | 阅读地图：5 个洞见、使用方法、内容说明 |
| 3-4 | 洞见 1：概念/边界；例子/SOP |
| 5-6 | 洞见 2：概念/边界；例子/SOP |
| 7-8 | 洞见 3：概念/边界；例子/SOP |
| 9-10 | 洞见 4：概念/边界；例子/SOP |
| 11-12 | 洞见 5：概念/边界；例子/SOP |
| 13 | 7 天行动计划与执行记录模板 |
| 14 | 批判性阅读、证据边界、版权声明 |

当内容需要 12、13 或 15 页时，可拆分行动页、案例页或版权与阅读边界页，但不得新增参考资料页，也不得改变“5 个洞见、每个含例子和 SOP”的信息架构。

## 3. 内容密度

- 每个洞见的概念页约 250-450 个中文字符。
- 每个洞见的案例/SOP 页约 350-550 个中文字符。
- 一张卡片只表达一个中心意思；同页卡片通常不超过 5 张。
- 每页必须有明显主标题与阅读路径。连续两页不得出现大段无层级文本。
- 读者版不显示引用编号、URL 或参考资料卡片；来源保存在内部 `sources.json`。

## 4. 生成与视觉检查

使用 `pdf` Skill 生成和检查。优先以 ReportLab 或项目已验证的确定性渲染方案构建 PDF，不依赖手工排版。

每次生成后必须：

1. 检查 PDF 文件可打开、页数 12-15、文件大小大于 50 KB 且小于 10 MB。
2. 提取全文，确认中文字符约 5,000-7,000、标题和 5 个洞见均存在。
3. 将全部页面渲染为 PNG，不能只查看封面。
4. 检查裁切、重叠、溢出、乱码、黑块、缺字、孤行、页码和链接区域。
5. 对至少第 1、2、3、4、13、14 页进行高分辨率人工或视觉模型复核；其余页面使用联系表扫描。
6. 确认正文未残留 `[S1]`、URL、脚注或参考资料页，同时内部 `sources.json` 完整可用。
7. PDF 生成或视觉检查失败时最多重新生成 2 次；之后将本次运行标记为失败，不发布。

生成的中间文件存放在运行目录，不覆盖历史成功产物。只有通过验收的 PDF 才能进入上传阶段。
