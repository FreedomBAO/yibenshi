# 发布验收规范

所有验收必须输出 JSON 报告。硬性项全部通过才允许上传或发布；验收脚本退出码为 0 表示通过，非 0 表示失败。

## 1. 内容验收

| 编号 | 硬性要求 |
|---|---|
| C01 | 书名、作者、版本/出版信息经至少 2 个来源核对 |
| C02 | 与 `data.json` 中历史书籍不存在书名、ISBN、版本级重复 |
| C03 | 正文约 4,000-7,000 个中文字符 |
| C04 | 恰好 5 个核心洞见，且每个包含机制解释与适用边界 |
| C05 | 每个洞见至少 2 个例子，全篇至少 10 个例子 |
| C06 | 事实案例、作者案例、合成情境均有明确类型标注 |
| C07 | 每个洞见包含 1 套 SOP，全篇恰好 5 套；每套 4-6 步 |
| C08 | 每套 SOP 包含触发条件、输入、输出和停止/升级条件 |
| C09 | 包含 7 天行动计划、批判性阅读和版权声明 |
| C10 | 未出现大段原文、逐章替代性摘要或来源不明的具体数字 |

## 2. 来源与证据验收

| 编号 | 硬性要求 |
|---|---|
| E01 | 至少 5 个可访问来源，其中至少 2 个第一方来源 |
| E02 | 每个经验性、统计性或因果性主张能映射到来源 |
| E03 | 使用 Consensus 的引用均具备 search 与 fetch 记录 |
| E04 | 研究结论未超出原来源的对象、时间、样本和因果边界 |
| E05 | 内部 `sources.json` 包含标题、机构/作者、URL、访问日期与支持的主张 |
| E06 | `sources.json` 中所有 URL 可访问；读者版 PDF 不含引用编号、URL 或参考资料页 |

## 3. PDF 验收

| 编号 | 硬性要求 |
|---|---|
| P01 | PDF 可打开，A4 竖版，页数 12-15，目标 14 |
| P02 | 文件大小 50 KB-10 MB，SHA-256 已记录 |
| P03 | 全部页面已渲染成图片并完成视觉扫描 |
| P04 | 无裁切、重叠、溢出、乱码、黑块、缺字或空白内容页 |
| P05 | 正文字号、行距、页边距和页脚安全区符合 `pdf-spec.md` |
| P06 | 封面、阅读地图、5 个洞见、行动计划、批判性阅读和版权声明齐全 |
| P07 | 页码连续，页眉与卡片组件风格一致 |
| P08 | 文本可提取，5 个洞见标题和书名均能在提取文本中找到 |

## 4. 数据与发布验收

| 编号 | 硬性要求 |
|---|---|
| D01 | `data.json` 是有效 JSON，字段类型符合现有契约 |
| D02 | 新记录位于首位，ID 唯一，当天只有一条记录 |
| D03 | `pdfUrl` 返回 200、`application/pdf`，远端大小与本地一致 |
| D04 | `cover` 可加载，或使用了项目自有文字封面 |
| D05 | `knowledge/books.json` 成功重建且包含当天书籍 |
| D06 | production 部署成功，不以 preview 替代 |
| D07 | 首页、详情/PDF 入口、搜索或 RAG 的完整用户故事通过 |
| D08 | 运行清单状态、提交哈希、部署 URL 和验收报告可追溯 |

## 5. 严重度与发布决策

- `P0`：错误书籍、重复发布、PDF 损坏、密钥泄露、链接指向错误文件。立即失败并阻止发布；若已发布，优先回滚公开目录。
- `P1`：任一硬性验收未通过，例如例子/SOP 数量不足、引用不可追溯、视觉不可读、网页关键入口失效。阻止发布并回到对应阶段修复。
- `P2`：不影响阅读和事实正确性的轻微视觉偏差。可记录为 warning，但同类 warning 连续 3 次必须升级为模板修复任务。

发布判定：`P0 = 0`、`P1 = 0`、所有 C/E/P/D 硬性项为 `pass`，且 `warnings` 不包含安全、版权、事实或可访问性风险。

## 6. 报告结构

```json
{
  "schemaVersion": "1.0",
  "runId": "2026-09-02-daily-book",
  "passed": true,
  "checkedAt": "2026-09-02T02:18:00+08:00",
  "summary": { "pass": 32, "fail": 0, "warning": 0 },
  "checks": [
    {
      "id": "C01",
      "status": "pass",
      "severity": "P1",
      "evidence": "source-manifest.json#book-metadata",
      "message": ""
    }
  ],
  "artifacts": {
    "pdfPath": "",
    "pdfSha256": "",
    "renderDirectory": "",
    "sourceManifest": "",
    "productionUrl": ""
  }
}
```

`evidence` 必须指向可检查的文件、URL、哈希、日志片段或渲染图，不能只写“已检查”。
