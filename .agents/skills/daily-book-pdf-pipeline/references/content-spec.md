# 选书、研究与内容规范

## 1. 目标读者与写作目标

- 读者：普通青年读者，不预设商业、心理学或金融专业背景。
- 阅读时间：18-22 分钟。
- 正文规模：5,000-7,000 个中文字符；内部来源记录与页眉页脚不计入目标字数。
- 成果目标：读者能复述 3 个关键判断，并在 24 小时内执行至少 1 个 SOP。
- 语气：清楚、具体、克制，不神化作者，不把相关性写成因果，不使用空泛励志口号。

## 2. 自动选书

### 2.1 候选范围

允许自由选择具备长期价值的非虚构图书。自我提升、金融商业、成长只是示例类别；也可覆盖决策、心理、沟通、职业、科技社会、健康习惯、历史中的现实启示等主题。

排除：纯小说、资料来源不足的冷门书、主要依赖未经证实轶事的书、内容明显鼓励危险或违法行为的书，以及无法在不复制原文的情况下形成独立精读的书。

### 2.2 去重与节奏

选书前读取 `data.json` 全量目录，并对中英文书名、作者、ISBN/版本信息和主题归一化。

- 同一书名、同一 ISBN 或仅版本不同：禁止重复。
- 同一作者：默认 90 天冷却，可由配置覆盖。
- 与最近 7 天主主题高度相似：默认避开；只有在有明确时效价值时允许，并在运行清单中说明。
- 同一大类连续出现 3 天：下一本优先选择其他大类。

### 2.3 评分

至少形成 3 本候选书并按下表评分，选择最高分且总分不低于 75 的一本：

| 维度 | 权重 |
|---|---:|
| 对普通青年读者的现实价值 | 25 |
| 可转化为行动的深度 | 20 |
| 可靠资料充足度 | 20 |
| 相对现有目录的新颖度 | 15 |
| 长期有效性 | 10 |
| 近期主题多样性 | 10 |

评分相同时，优先选择资料更充分、能形成更具体 SOP 的书。候选及评分进入运行清单，不进入读者版 PDF。

## 3. 研究资料包

写作前建立来源清单和“主张-证据表”。不得只依赖搜索摘要、书商简介或模型记忆。

来源清单保存为内部 `sources.json`，不得放进读者版 PDF。`sources.json` 应位于当次运行目录而非公开上传目录，保留供 Codex 验收和事实追溯。

最低来源要求：

- 总计至少 5 个可访问来源。
- 至少 2 个第一方来源，例如作者官网、出版社页面、作者演讲或访谈、官方研究页面。
- 经验性或统计性主张优先使用原始论文、官方数据或权威机构资料。
- 可使用可靠书评和访谈辅助理解，但不得把二手观点冒充作者原意。
- 每条来源记录标题、作者/机构、URL、访问日期、支持的主张和来源类型。

使用 Consensus 时：

1. 将需要验证的经验性主张改写成可检索问题。
2. 先调用 Consensus search 获取候选研究。
3. 对拟采用的研究调用 fetch，核对摘要、方法、年份与结论边界。
4. 只有 fetch 成功且结论与正文一致时才写入引用。
5. 若研究互相冲突，在正文呈现不确定性，不挑选单一结论制造确定感。

## 4. 固定内容结构

正文必须包含以下模块：

1. 一句话价值：这本书帮助读者解决什么现实问题。
2. 阅读地图：5 个核心洞见及彼此关系。
3. 五个核心洞见：每个洞见按同一模板展开。
4. 7 天行动计划：将 5 个 SOP 编排成可启动的小实验。
5. 批判性阅读：适用边界、争议、证据强弱和不应照搬之处。
6. 版权声明与阅读边界；参考资料只进入内部 `sources.json`。

读者版 PDF 不显示 `[S1]` 等引用编号、脚注、URL 或参考资料页。隐藏引用只改变阅读界面，不降低研究、核实或主张-证据映射要求。

### 每个洞见的固定模板

- `核心判断`：一句可复述的判断。
- `为什么成立`：解释机制，不只列结论。
- `适用边界`：至少说明一个不适用或需谨慎的条件。
- `例子 A` 与 `例子 B`：至少两个不同情境。
- `可执行 SOP`：4-6 个编号步骤。
- `自检问题`：一个能判断是否理解或执行到位的问题。

### 例子规范

- `[书中/作者案例]`：仅在有可靠来源时使用，并保持简短转述。
- `[事实案例]`：须有可追溯来源，不得改写关键数字或因果关系。
- `[合成情境]`：为解释概念构造，必须明确标注，人物与数字不得暗示真实来源。
- 五个洞见合计至少 10 个例子；避免只换姓名、行业或金额的重复例子。

### SOP 规范

每套 SOP 必须可由读者独立执行，并包含：

- 触发条件：什么时候使用。
- 所需输入：时间、信息或工具。
- 4-6 个按顺序编号的动作。
- 预期输出：完成后留下什么可检查结果。
- 停止或升级条件：何时不应继续，何时需要专业帮助或更多信息。

不得使用“多思考”“保持自律”“持续学习”这类不可验收动作。动作应具体到可以在日历、表格、笔记或现实行为中留下痕迹。

## 5. 版权与事实边界

- 不获取或使用盗版全文，不绕过付费墙，不复制章节、图表或练习题。
- 默认全部转述。单一来源的直接引文不超过 25 个英文词或等量短句，且全文尽量不用直接引文。
- 不按原书章节顺序复刻全书，不提供足以替代购买或阅读原书的逐章摘要。
- 书名、作者、出版社、出版年份等基础信息至少由两个来源交叉核对。
- 金融、健康、法律等内容须明确其教育用途，并给出必要的专业建议边界。
- 文末声明：本文为基于公开资料的原创学习导读，不是原书替代品；建议支持正版并结合原书阅读。
